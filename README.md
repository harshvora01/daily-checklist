# Forge — V-Taper Tracker

Offline fitness + habit app for an 8-week cut & build. Install it from **harshvora01.github.io/daily-checklist** (Safari → Share → Add to Home Screen).

- **Today:** habit rings, session card, water and smoothie taps, streak
- **Train:** 5-day V-taper program, set logger with previous numbers, auto weight increases, rest timer, PRs
- **Fuel:** calorie + protein targets (Mifflin-St Jeor, 20% deficit, 1 g protein per lb), quick-add chips
- **Body:** weight trend with 7-day average, measurements, shoulder:waist gauge (target 1.6)
- **Stats:** 26-week heatmap, weekly volume, est. 1RM trends, milestones

Data is stored on the device. Use Stats → Settings → Export for backups.
